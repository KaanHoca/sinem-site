# sinem.site — Proje Bağlamı

> Bu dosya Projeler Günlük Sistemi tarafından okunur.

## Amaç
**sinem.site** — kişisel ya da küçük bir marka için tanıtım/portfolio sitesi. Proje henüz erken aşamada ve çok minimal.

## Teknoloji
- **Next.js 16.2.1** (App Router)
- **React 19.2.4**
- **TypeScript 5**
- **Tailwind CSS 4**
- **ESLint 9** + eslint-config-next

## Yapı
```
sinem.site/
├── src/
│   ├── app/                ← Next.js App Router
│   └── data/               ← statik veri muhtemelen
├── public/
└── .vercel/                ← Vercel deploy
```

## Deploy
- **Vercel** üzerinde deploy ediliyor (`.vercel/` klasörü mevcut)

## Proje Dosyaları
- `AGENTS.md` — agent talimatları
- `CLAUDE.md` — minimal (11 byte)
- `README.md` — default Next.js template

## Teknik Notlar
- En minimal bağımlılık listesi: sadece `next`, `react`, `react-dom`
- framer-motion veya lucide-react bile eklenmemiş
- Backend yok
- `src/data/` klasörü ile statik içerik yönetiliyor gibi
- Muhtemelen henüz tasarım/yapı aşamasında, üzerine içerik gelecek
